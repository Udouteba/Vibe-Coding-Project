## ⚠️ 关键踩坑经验（最重要，后续会话必读）

### 1. PaddleOCR 依赖版本矩阵（Windows + Python 3.12 + CPU）
最终锁定在 `backend/requirements.txt`：
```
paddlepaddle==3.2.0
paddleocr==3.5.0
numpy==1.26.4
pandas<3.0
```
踩坑过程：
- **paddle 3.3.x oneDNN PIR 回归**：默认推理报 `NotImplementedError: ConvertPirAttribute2RuntimeAttribute`；`enable_mkldnn=False` 则 segfault → 降级 `paddlepaddle==3.2.0`
- **paddle CPU 卷积核 bug**：大图（边长>~1400px）推理 segfault，小图正常 → `OCR_DPI=120` + `OCR_MAX_SIDE=1400` 等比缩小规避
- **paddle + numpy 2.x 组合 segfault**：降级 `numpy==1.26.4`（paddlex 要求 `<2.4`）
- **torch（sentence-transformers）与 paddle 的 OpenMP 运行时冲突**：`config.py` 顶部 `os.environ.setdefault("KMP_DUPLICATE_LIB_OK", "TRUE")`
- **PPStructureV3 API**：paddleocr 3.x 里 PP-Structure 改名为 `PPStructureV3`（非 `PPStructure`）；`predict()` 只接受 `numpy.ndarray`/`str`（不接受 PIL.Image）；返回 `LayoutParsingResultV2`（dict-like，用 `r["parsing_res_list"]` 访问，每块有 `label/content/bbox/order_index`）

### 2. Rerank 模型下载：hf-mirror 限流
bge-reranker-base 走 hf-mirror 下载触发 **429 限流**（xet-read-token 接口），改用 **modelscope** 下载成功：
`~/.cache/modelscope/models/BAAI--bge-reranker-base/snapshots/master`。
`get_reranker()` 里 `_find_local_reranker()` 优先读 modelscope 本地缓存，回退 HF 名。

### 3. Rerank 只排序、score 保留 cosine
bge-reranker 输出 logit（非 [0,1]），若替换 score 会使 `RETRIEVE_MIN_SCORE=0.25` 失效。实现为 rerank 只决定排序，`item["score"]` 保留 cosine 值。
